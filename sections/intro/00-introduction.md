# Introduction

Welcome. This course teaches you how to set up a Kubernetes cluster in a secure way. Cluster Setup is one of the domains of the Certified Kubernetes Security Specialist (CKS) exam, and it is worth 15% of the score. The CKS exam is a hands-on test: you solve real tasks on real clusters from the command line.

Before the technical part starts, take a few minutes to read the three short pages of this introduction. They explain what you will learn, what you need on your computer and how the course is made.

The first page, Welcome To The Course, says who the course is for and what you can do when you finish it. It also explains how each section and module is built, and how the readings, playgrounds and graded labs fit together. A playground is a private practice cluster that runs on your own machine.

The second page, Get Your Machine Ready, lists the tools to install and the commands you use every day to start and stop a playground. Do this page before the first module, so you can follow every hands-on step.

The third page, How This Course Is Made, explains how the authors write and check the content. It also tells you who maintains the course and how to report a mistake when you find one.

After the introduction, the course starts with network security. You learn how a NetworkPolicy, a Kubernetes object that controls which traffic can reach a pod or leave it, limits access inside the cluster.
