# Starting Environment

The lab VM runs a one-node Kubernetes cluster built with kubeadm, the standard tool that installs a cluster on a Linux machine. The node `astro-ats-031-lab-020-02-03` is the control plane and also runs the pods. The `starfleet-031-020-02-03` namespace runs two `probe` replicas behind the `probe` Service and a `shuttle` client pod. The `kube-bench` image `docker.io/aquasec/kube-bench:v0.10.6` is already loaded on both nodes. No kube-bench Job exists.

Write and run a kube-bench Job that runs the worker node checks with the `node` target and reads the node processes and files.
