# Capstone: Verify Before You Deploy Lab

The capstone lab for this section. The learner verifies a signed release bundle, rejects the altered binary, checks the running `kubelet` and pins an image by digest, then records a verification report.

There is no step-by-step guide until the learner has tried the task. The learner works from the specification in `question.md`. Author verification is under testing; runtime verification is pending.
